# Kuma Write

用 Rust（egui/eframe）寫的沉浸式寫作軟體，靈感來自 OmmWriter、FocusWriter 與小黑屋。

## 執行

Linux 編譯前需要 ALSA 開發套件（音訊用）：

```sh
sudo apt install libasound2-dev pkg-config
cargo run --release
```

文件存在 `~/文件/KumaWrite/`（依系統的「文件」資料夾而定），格式為純文字 `.md`，停止打字約 1 秒後自動儲存。
設定與小黑屋狀態存在 `~/.local/share/kuma-write/`。

## 介面

畫面上只有文字與背景的景。每個主題都是一幅由程式即時繪製的風景（漸層天空、日月光暈、層層遠山與霧，再加上細微的顆粒與暗角），不使用任何圖檔。
移動滑鼠時，上方選單與下方狀態列會浮現；開始打字就會淡出，滑鼠游標也會隱藏。按 `Esc` 可讓選單常駐。

| 快捷鍵 | 功能 |
| --- | --- |
| `Ctrl+O` / `Ctrl+N` | 文件列表 / 新文件 |
| `Ctrl+S` | 立即儲存 |
| `Ctrl+E` | 匯出 TXT（存到文件資料夾下的 `匯出/`，檔名取自第一行） |
| `Ctrl+T` | 切換場景（雪、夜、紙、森、暮） |
| `Ctrl+=` / `Ctrl+-` | 放大 / 縮小字級 |
| `F8` | 專注段落：淡化目前段落以外的文字 |
| `F9` | 打字機模式：正在寫的那一行保持在畫面中央 |
| `F11` | 全螢幕 |
| `Ctrl+L` | 小黑屋 |
| `Ctrl+Q` | 離開 |

選單中的「外觀」可以點選場景縮圖，並調整字體、字級、行距、欄寬與專注模式。

字數統計：中日韓文字每字算 1，英文等以單字計算，標點不計。

## 聲音

選單中的「聲音」可以選擇背景音與打字音效，各自調整音量。所有聲音都由程式即時合成，不需要音檔。

- 背景：雨、海浪、風、爐火、冥想（緩慢變換的和弦）
- 打字音效：輕觸、打字機（換行有捲紙聲與鈴聲）、水滴
- 使用中文輸入法時，組字過程中每按一個鍵也會有聲音

Linux 上會透過 PulseAudio／PipeWire 播放。

## 每日統計

選單中的「統計」會顯示今日字數、寫作時間、連續寫作天數、每日目標進度，
以及近 30 天的字數長條圖（滑鼠移到長條上可看明細）。
字數為當天所有文件的淨增字數，寫作時間只計算有在打字的時段（停筆超過 20 秒不算）。
紀錄存在 `~/.local/share/kuma-write/journal.json`。

## 小黑屋

可以設定「寫滿 N 分鐘」、「新增 N 字」，或兩者都要。進入後：

- 無法關閉視窗（關閉請求會被攔下）、無法離開全螢幕、無法切換文件
- 視窗置頂；切到別的視窗或被最小化時，會自動搶回焦點，並記錄一次「逃跑」
- 狀態寫入磁碟。強制結束程式後再開，會接著鎖在同一份文件上；
  計時只在程式開著時累積，所以關掉程式並不能讓時間跑完
- 若進入前勾選「緊急出口」，可以一字不差地抄寫一段句子後離開

### 限制

一般應用程式無法完全攔截作業系統層級的操作，例如切換虛擬桌面、`Ctrl+Alt+F3` 切到其他終端、
從工作管理員結束程序，在 Wayland 下視窗管理員也可能拒絕搶焦點。這些操作不會被阻止，
但小黑屋的狀態會保留，下次開啟時依然要寫完。

## 自訂字型

程式會透過 `fc-match` 尋找系統的繁體中文字型，偏好細字重（例如 Noto Serif CJK TC Light），明體／黑體可在「外觀」切換。
若要指定字型，可在 `config.json` 中設定 `"font_path": "/path/to/font.ttf"`。
