# 音效來源

`typewriter/` 裡是打字機的錄音，取自 [Tickeys](https://github.com/yingDev/Tickeys)
（Copyright (c) 2015 YingDev.com），以 MIT 授權，授權條文見 `typewriter/LICENSE`。

| 檔案 | 原始檔名 | 用途 |
| --- | --- | --- |
| `key1.wav`–`key5.wav` | `key-new-01.wav`–`key-new-05.wav` | 一般按鍵，每次隨機挑一個 |
| `space.wav` | `space-new.wav` | 空白鍵 |
| `backspace.wav` | `backspace.wav` | 退格 |
| `return.wav` | `return-new.wav` | 換行 |
